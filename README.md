# terra-data

Data files for the Terra app. Data only: no program code lives here.

| Release | File | What it is |
|---|---|---|
| `unidic-accent-3.1.0` | `unidic-accent-3.1.0.sqlite.gz` | Pitch accent of Japanese base forms and readings, derived from UniDic-cwj 3.1.0 (344,508 rows). |

Each release carries a `.sha256` file for its table and a `NOTICE.md` with the licence text and attribution
(UniDic: BSD License, (c) The UniDic Consortium, source NINJAL). See `NOTICE.md` before reusing the data.
